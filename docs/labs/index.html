Labs · Browser tools, apps and experiments

Labs: things I build because I want them to exist.

Free browser tools, offline-first apps and hardware experiments, built to the same standard as client work. No account, no upload, no trial that runs out.

  • browser Everything happens in the tab. Nothing you paste or drop is sent anywhere, because there is nothing in the page that could send it.
  • download Take the whole tool as one HTML file. It keeps working with the wifi off, on any device, with nothing else installed.
  • self-host Put that file on your own server, or on an intranet with no route out to the internet at all.

Built something you'd want to see here? Found a bug? hello.beben.design@gmail.com
