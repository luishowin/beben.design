ARCADIA is a pocket arcade — tiny 8-bit games, zero ads, zero sign-ups, zero tracking. It plays offline, keeps your best scores on your device, and never phones home.

Built with plain HTML, CSS and JavaScript: canvas rendering, a service worker for offline installs, self-hosted pixel type, no frameworks. A design project by Luis Howin, creative director at BEBEN DESIGN — about 99% of the code was written with AI.

Have fun. And tell a friend to tell a friend.
