// Questions

Good to know

Is this QR code generator really free

Yes. No account, no watermark, and no limit on the number of codes. Every feature on this page is included.

Do the codes expire

No. A QR code carries its own text, so a saved SVG or PNG scans forever, whether or not this page still exists.

What can a code hold

URLs, plain text, phone numbers, and contact details typed as text. Longer text draws a denser matrix, so short links scan the easiest.

Is anything uploaded

No. Content and logos stay in the browser tab, and the downloaded single file works offline. Nothing typed here reaches a server.

Why do some styled codes fail to scan

Scanners need contrast and intact corner marks. Keep dark ink on a pale ground, test rounded or circular finders on the target reader, and pair logos with H error correction at modest sizes.

SVG or PNG, which export should be picked

SVG for print and signage, since vectors scale without end. PNG for documents and slides that need pixels. Both carry the same design.
